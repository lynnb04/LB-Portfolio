# Lynn Bolderman - Portfolio

Dit is de repository voor mijn persoonlijke portfolio. Deze website is gebouwd als onderdeel van mijn studie Communication & Multimedia Design (CMD) aan de Hogeschool van Amsterdam, waar ik me specialiseer in frontend development.

## Kenmerken
- **Design:** Een ontwerp gebaseerd op glassmorphism met geanimeerde achtergronden opgebouwd uit CSS blobs.
- **Meertalig:** De website bevat een script om zonder herladen te wisselen tussen Nederlands en Engels.
- **Donkere modus:** De donkere en lichte modus werken volledig op basis van CSS variabelen.
- **Modals:** Voor de popups is gebruik gemaakt van de native HTML Popover API in plaats van externe libraries.
- **CSS Architectuur:** De CSS is opgedeeld in losse modules (zoals layout, componenten en variabelen) en wordt samengevoegd via de hoofd-stylesheet.

## Gebruikte technieken
- HTML5 (Inclusief de Popover API)
- CSS3 (Variabelen, animaties, flexbox en grid)
- Vanilla JavaScript
- Lettertype: Outfit (Google Fonts)

## Lokaal draaien
Deze website bestaat volledig uit statische bestanden. Er is geen build proces nodig.

1. Clone deze repository:
   ```bash
   git clone https://github.com/lynnb04/LB-Portfolio.git
   ```
2. Open de map:
   ```bash
   cd LB-Portfolio
   ```
3. Open `index.html` in een browser of gebruik een lokale server (zoals de Live Server extensie in VS Code).

# Lynn Bolderman - Portfolio (English)

This is the repository for my personal portfolio. This website was built as part of my Communication & Multimedia Design (CMD) studies at the Amsterdam University of Applied Sciences, where I specialize in frontend development.

## Features
- **Design:** A design based on glassmorphism with animated backgrounds created using CSS blobs.
- **Multilingual:** The website includes a script to switch between Dutch and English without reloading.
- **Dark mode:** The dark and light mode toggle operates entirely on CSS variables.
- **Modals:** The native HTML Popover API is used for the popups instead of external libraries.
- **CSS Architecture:** The CSS is split into separate modules (such as layout, components, and variables) and combined through the main stylesheet.

## Built with
- HTML5 (Including the Popover API)
- CSS3 (Variables, animations, flexbox, and grid)
- Vanilla JavaScript
- Font: Outfit (Google Fonts)

## Running locally
This website consists entirely of static files. No build process is required.

1. Clone this repository:
   ```bash
   git clone https://github.com/lynnb04/LB-Portfolio.git
   ```
2. Open the directory:
   ```bash
   cd LB-Portfolio
   ```
3. Open `index.html` in a browser or use a local server (like the Live Server extension in VS Code).
